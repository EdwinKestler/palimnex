Architecture

Two memory planes. One clear authority model.

Redis accelerates discovery. SQLite preserves accepted historical events. Repository files remain the current source of truth.

Pipeline flows

Evidence enters through controlled, inspectable paths.

A

Verified source retrieval

Fast candidates, current bytes.

  1. 1Privacy scanReject credential-shaped content before derivation.
  2. 2Build postingsStore digests, vectors, graph metadata—never source bodies.
  3. 3Bound candidatesBM25-style lookup touches at most 512 chunks.
  4. 4Reopen sourceVerify file and chunk digests against the checkout.
  5. 5Return evidenceRanked text with score components and source pointers.
B

Durable memory

Commit before projection.

  1. Validate event + evidenceTyped schema, current source locator, privacy policy.
  2. SQLite transactionEvent and outbox row commit atomically.
  3. Redis hot projectionBounded metadata only; retries are idempotent.
  4. Recall with trust filtersTime, sensitivity, retention, history, and verification.
C

Authorized erasure

Explicit, local, verifiable.

  1. Authorize + bind planShort-lived authority, reason code, current ledger digest.
  2. Enforce holds + dependenciesProtected anchors and unresolved stores fail closed.
  3. Rewrite + recomputeRemove content and derivatives; withdraw unsupported facts.
  4. Verify + tombstoneCompact locally and preserve non-reconstructive audit residue.

Quick start

From checkout to verified retrieval.

Run from the repository root. The guarded launcher creates a private Redis instance under ignored local state.

$ python3 palimnex.py status
$ python3 palimnex.py index --incremental
$ python3 palimnex.py validate --deep
$ python3 palimnex.py evaluate --limit 5
$ python3 palimnex.py ledger-status

✓ fresh cache · deep validation passed

Safety boundary

Recall informs. It never authorizes.

Cache hits, durable records, imported packs, and remembered workflows cannot grant permission to commit, push, deploy, spend, erase, contact a provider, or change an external system. Current authorization always comes from the current operator and repository context.
